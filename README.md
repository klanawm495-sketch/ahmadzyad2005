# الواجب الثاني: إنشاء صفحة HTML ورفعها على GitHub

## وصف المشروع
هذا المشروع هو تطبيق عملي لمتطلبات مساق **تصميم وإدارة مواقع الإنترنت**[cite: 7]، حيث تم بناء هيكلية صفحة هبوط (Landing Page) متكاملة باستخدام لغة HTML5 مع دمج الصورة المرفقة في الواجب (`landing.jpg`)[cite: 7].

## محتويات المستودع
* **`index.html`**: يحتوي على الكود البرمجي الأساسي للصفحة، مقسماً إلى أقسام واضحة (`Header`, `Landing`, `Services`, `Contact`, `Footer`) مع إضافة تعليقات (`Comments`) توضيحية لكل جزئية[cite: 7].
* **`images/landing.jpg`**: مجلد الصور ويحتوي على الصورة الرئيسية المستخدمة في الصفحة[cite: 6, 7].
* **`README.md`**: ملف توضيحي يشرح فكرة المشروع وهيكلية الكود[cite: 7].
